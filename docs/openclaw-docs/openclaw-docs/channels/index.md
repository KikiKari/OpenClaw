- Discord — Bot API + Gateway

- Google Chat — HTTP Webhook
- iMessage (legacy, deprecated)
- IRC — Classic IRC
- LINE — Messaging API (Bundled Plugin)
- Matrix — Protocol (Bundled Plugin)
- Mattermost — Bot API + WebSocket (Bundled Plugin)
- Microsoft Teams — Bot Framework (Bundled Plugin)
- Nextcloud Talk (Bundled Plugin)
- Nostr — NIP-04 DMs (Bundled Plugin)
- QQ Bot — Private + Group Chat (Bundled Plugin)
- Signal — signal-cli
- Slack — Bolt SDK
- Synology Chat — Webhooks (Bundled Plugin)
- Telegram — grammY Bot API
- Tlon — Urbit (Bundled Plugin)
- Twitch — IRC (Bundled Plugin)
- Voice Call — Plivo/Twilio (Plugin)
- WebChat — Gateway UI
- WeChat — iLink Bot (External Plugin)
- WhatsApp — Baileys + QR
- Zalo — Bot API (Bundled Plugin)
- Zalo Personal — QR Login (Bundled Plugin)
