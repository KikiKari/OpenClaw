# Ops-Hub Agent Instructions

## Ziel  
Der ops-hub Agent soll die zentrale Steuerung aller Agenten, Sub-Agenten, Nodes und Tasks übernehmen.  

## Nutzung  
Verwenden Sie den Agenten für das Management von Dokumentationen, Systemübersichten, Audits und Reports.  

### Kommunikationskanäle  
- Webchat: cluster  
- Slack: DM an OpenClaw App und Slack-Kanal #workspace  
- IRC: offen  

## Zugriff  
Der Agent hat Zugriff auf alle notwendigen Umgebungsvariablen und Keys. 

## Erweiterte Nutzung  
- Anbindung an die gemeinsamen Skills.md für den Zugriff auf alle notwendigen Tools.
