# WAS: WebSearch - Dokumentation

# - WebSearch & Memory Assistant - (C)2026 by claw

Enthält alle Anweisungen und Informationen zur Nutzung, Konfiguration und den Betrieb mit API:

Tavily, Serperdev oder Kimi Suchserver

Diese Dokumentation dient als Leitfaden und Informationsquelle für WebSearch - Prozesse.

Das Ziel dieses Projektes ist die bestmögliche Bereitstellung des Abfrage Befehls für:
Suchanfragen, korrigierte Antworten und die perfekte Extraktion mit KI/MCP.

### Module

1.  Einrichten
2.  Bedienung
3.  Infrastruktur
4.  Optimierung

### Installation
Zur Ausführung der Installation wird ein direkter Key benötigt.

Direkter Installations Link:

> ./autoinstall.sh

### Optimierung
Zur Optimierung der Abfrage stehen mehrere Einstellungen zur Verfügung.

1.  Provider (OpenSource, COM, API)
2.  MCP Level 1-3
3.  Feintuning
   4.  Extraktions Verfahren
